# LargeScaleProgramming
## 介绍
本项目是开源安全即时通讯软件，致力于为用户提供安全、高效的即时通讯服务
## 系统功能
- 用户友好界面：本项目实现了密码登录、验证码登录和注册登录三种登录方式。在用户使用界面，可以对通讯录好友进行增删，并实现收发在线好友的信息。用户可以通过使用界面进行便捷操作；有输入信息错误会及时反馈给用户，并且有充分的用户提示，提供良好的体验性。
- 加密通讯：在传输过程中采用RSA加密方式协商秘钥，并使用AES实现信息内容传输的加解密，有效保障了加密的可靠性。在服务器一端，我们的程序可以对用户的注册信息进行存储和验证，并通过SHA256加密方法保障了存储信息的安全性。
- 安全日志：服务器可以在用户使用期间记录保存用户的在线状态、IP地址、 端口号等数据。
## 设计亮点
- 采用python进行全程序自主编程，代码具有良好的可移植性和操作性，能够根据需求随时更改各功能部分。
- 使用云服务器部署服务器端，保证系统随时在线，能够24h实现通信。
- 添加控制层，使前后端交互更加流畅，减少前后端开发时人员交流成本。
- 本项目实现了高并发技术进行运行，使得项目具有较高的弹性，可以容纳较多使用用户同时通信，符合一个即时通讯系统用户量大，用户请求多的特点
- 采用异步方式处理服务器和客户端请求，有效提升系统的健壮性，在高负载和资源情况有限的条件下可以更好的满足用户的需求。
